To validate whether any lab complies with our Proof-of-Learning standards, refer to the master validation contracts:

* 🧪 **[LAB_TEMPLATE.md](file:///home/rahul/3-labs/devops-engineer/LAB_TEMPLATE.md)**: Copy-paste template for logging new experiments.

### Core Rules Overview:
1. **Naming Conventions**: Always use lowercase kebab-case (e.g., `1-crypto-conversion-api`, `aws-linux-server`). No spaces, camelCase, or random underscores.
2. **Git Integrity**: Never create nested `.git` directories.
3. **Proof-of-Learning Standard**: Every lab MUST contain a local `README.md` with:
   - `🎯 Objective`
   - `🚀 Procedure & Execution`
   - `📸 Proof of Learning (Evidence Output Log)`
   - `💡 Key Takeaways & Gotchas`
